``ansible.cfg`` in your project

if you type 
```bash
ansible --vesion # in dir that have ansible.cfg 
```
the output will be like that
```bash
ansible [core 2.18.12]
  config file = /home/abdallah-shehawey/keys/ansible.cfg
```
if not have ansible.cfg the output will be with default config file 
```bash
ansible [core 2.18.12]
  config file = /etc/ansible/ansible.cfg
```
and if not have default config file the output will be none
